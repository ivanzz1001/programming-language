# 现代C++值类别体系(C++11起)


`C++11`引入了移动语义，值类别被重新定义为核心的三类:

- 左值（lvalue）
- 纯右值（prvalue）
- 将亡值（xvalue）

并由此组合出`泛左值(glvalue)` 和`右值(rvalue)`:

```text
       expression
       /        \
   glvalue     rvalue
    /    \     /    \
lvalue   xvalue   prvalue
```

下面简单介绍一下:

1. **左值(lvalue)**: 具有身份，且不可移动(仍未传统左值)

1. **将亡值(xvalue)**: 具有身份，但可以被移动（例如 std::move() 返回的值、某些类型转换的结果）

1. **纯右值(prvalue)**: 没有身份，用于初始化或运算（如临时对象、字面量）

1. **泛左值（glvalue）**  = 左值 + 将亡值（有身份）。

1. **右值（rvalue）** = 将亡值 + 纯右值（可移动）。

在这个体系中，左值依然是核心，但将亡值也拥有身份（可取地址），却被视为右值引用，可以被移动。
