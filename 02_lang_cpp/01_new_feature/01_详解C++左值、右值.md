## 1. C++左值详解

在`C++`中，左值（lvalue） 是表达式的一种值类别（value category），它表示一个具有身份（identity）且不能被移动的对象（或`位域`）。简单来说，左值指向一个明确的内存位置，你可以取得它的地址，并且它在表达式结束后依然存在。

理解**左值**是掌握 C++ 基础的关键，特别是随着`C++11`引入移动语义和右值引用后，值分类变得更加精细，但左值的核心概念依然不变。

### 1.1 历史起源：为什么叫“左值”？

名字源自`C语言`: **左值**是指可以出现在赋值运算符左侧的表达式。例如：

```cpp
int x = 42;
x = 100;            // x 是左值，因为它可以出现在 = 左边
```

相应地，**右值**（rvalue） 最初指只能出现在赋值右侧的表达式，如字面量`42`或临时计算结果。

不过在现代`C++`中，这种简单的左右划分已经不够用了，但名字保留了下来。

### 1.2 左值的核心特征
一个表达式是左值，当且仅当它具备以下特征:

1. **可以取地址**

   使用`&` 运算符能获得其内存地址
   ```cpp
   int x = 10;
   &x;               // 合法，x 是左值
   // &42;           // 错误，42 是右值，不能取地址
   ```

1. **有持久的状态**

   左值通常对应一个`变量`、`函数`、`数组元素`、`数据成员`等，其生命周期由作用域决定

1. **可以出现在赋值左边（除非被const修饰)**

   ```cpp
   const int c = 5;
   c = 10;        // 错误：c 是左值，但不可修改
   ```

1. **可以隐式转换为右值**

   当需要一个右值时，左值会自动进行左值到右值转换（例如作为算术运算符的操作数）

### 1.4 左值引用（lvalue reference）

C++ 使用`&`声明左值引用，它只能绑定到左值（或某些特殊情况下的`const`左值可绑定到右值，但那是例外）。

```cpp
int x = 10;
int& ref = x;                // 合法，ref 绑定到左值 x
// int& ref2 = 20;           // 错误：20 是右值，不能绑定到左值引用

const int& ref3 = 30;        // 合法：const 左值引用可以延长右值的生命周期
```
左值引用常用于避免拷贝、实现输出参数等。

### 1.5 如何判断一个表达式是左值？

- 使用`decltype((expr))`

  - 返回 T&：expr 是左值；
  - 返回 T&&：expr 是将亡值，不是左值；
  - 返回非引用 T：expr 是纯右值。

  参看如下示例:
  ```cpp
  int x = 0;
  int& r = x;
  int&& rr = 0;

  // 左值
  static_assert(std::is_lvalue_reference_v<decltype((x))>);      // true
  static_assert(std::is_lvalue_reference_v<decltype((r))>);      // true
  static_assert(std::is_lvalue_reference_v<decltype((rr))>);     // true，rr 表达式是左值
  static_assert(std::is_lvalue_reference_v<decltype((++x))>);    // true

  // 将亡值：decltype((expr)) 是 T&&，不是左值引用
  static_assert(!std::is_lvalue_reference_v<decltype((std::move(x)))>); // true

  // 纯右值：decltype((expr)) 是非引用
  static_assert(!std::is_lvalue_reference_v<decltype((x + 1))>); // true
  static_assert(!std::is_lvalue_reference_v<decltype((x++))>);   // true
  ```

- 尝试取地址

  若 `&expr` 合法，则 `expr` 是左值（或将亡值，但将亡值取地址也是合法的）。

- 标准库类型萃取

  std::is_lvalue_reference()、std::is_rvalue_reference()等可以判断引用类型，但不能直接判断值类别。

**常见的左值产生方式**：

- 变量名、函数名（函数类型是左值？注意函数本身不是数据对象，但函数指示符在某些语境是左值）
- 返回左值引用的函数调用
- 内置赋值、复合赋值、前置自增/自减运算符的结果
- 字符串字面量
- 成员访问（如果成员本身是左值）

### 1.6 左值到右值转换

当需要一个右值（如进行算术运算）而提供了一个左值时，编译器自动执行 左值到右值转换，读取左值的内容产生一个纯右值。

```cpp
int x = 10;
int y = x + 5;   // x 是左值，但加法需要右值，所以发生左值到右值转换，读取 x 的值 10
```

这种转换不会改变左值本身，只是提取它的值。

### 1.7 左值在移动语义中的角色

移动语义主要针对右值（尤其是将亡值），但左值也可以显式转换为右值使用`std::move()`:

```cpp
std::vector<int> v1 = {1,2,3};
std::vector<int> v2 = std::move(v1);  // v1 被转换为将亡值，资源被移动
// 移动后 v1 处于有效但未指定状态
```

这里`std::move(v1)`产生一个将亡值，它有身份（仍可取地址），但被当作右值绑定到移动构造函数，从而窃取资源。

>注：如何理解上面的“移动后v1处于有效但未指定状态”？
>
> 1）**“有效”回答的是：能不能安全地用？**
>
> 有效（valid） 指的是：对象仍然满足它所属类型的不变量（invariant），处于一个合法的、可以安全操作的状态
>
> 2）**“未指定”回答的是：它的具体内容是什么？**
>
> 未指定（unspecified） 指的是`C++标准`不规定移动后对象内部的具体值/状态。不同的标准库实现可以做出不同选择，标准不要求`v1.size() == 0`，也不要求`v1.capacity()`是多少，更不要求`v1`里还残留什么元素。

### 1.8 总结

掌握左值的概念，能帮助你写出更高效、更正确的 C++ 代码，尤其是在涉及引用和移动操作时:

- `左值`是代表内存位置的表达式，可以取地址、有持久身份;
- 它可以是变量、数组元素、解引用的指针、返回左值引用的函数调用等
- 左值引用 `T&` 绑定到左值，const 左值引用可绑定到右值以延长生命周期。
- 现代`C++`中，左值与将亡值、纯右值共同构成精细的值类别体系，但左值仍是其中最基本的一类
- 理解左值是理解引用、移动语义、完美转发等高级特性的基石。
