## 1. C++左值详解

在`C++`中，左值（lvalue） 是表达式的一种值类别（value category），它表示一个具有身份（identity）且不能被移动的对象（或位域）。简单来说，左值指向一个明确的内存位置，你可以取得它的地址，并且它在表达式结束后依然存在。

理解**左值**是掌握 C++ 基础的关键，特别是随着`C++11`引入移动语义和右值引用后，值分类变得更加精细，但左值的核心概念依然不变。

### 1.1 历史起源：为什么叫“左值”？

名字源自`C语言`: **左值**是指可以出现在赋值运算符左侧的表达式。例如：

```cpp
int x = 42;
x = 100;            // x 是左值，因为它可以出现在 = 左边
```

相应地，**右值**（rvalue） 最初指只能出现在赋值右侧的表达式，如字面量`42`或临时计算结果。

不过在现代`C++`中，这种简单的左右划分已经不够用了，但名字保留了下来。

### 1.2 左值的核心特征
一个表达式是左值，当且仅当它具备以下特征:

1. **可以取地址**

   使用`&` 运算符能获得其内存地址
   ```cpp
   int x = 10;
   &x;               // 合法，x 是左值
   // &42;           // 错误，42 是右值，不能取地址
   ```

1. **有持久的状态**

   左值通常对应一个`变量`、`函数`、`数组元素`、`数据成员`等，其生命周期由作用域决定

1. **可以出现在赋值左边（除非被const修饰)**

   ```cpp
   const int c = 5;
   c = 10;        // 错误：c 是左值，但不可修改
   ```

1. **可以隐式转换为右值**

   当需要一个右值时，左值会自动进行左值到右值转换（例如作为算术运算符的操作数）
